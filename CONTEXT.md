# Domain language

- **Agent run envelope**: the versioned, JSON-safe request contract created after ingress authentication and protocol validation but before agent, provider, tool, or MCP initialization. It carries only the validated protocol payload and the minimum trusted principal identifiers. The execution host rehydrates all runtime state from those identifiers.
- **Theme definition**: a versioned, data-only description of LibreChat semantic colors and shared appearance roles, optionally specialized by light or dark mode. The theme module validates and resolves partial definitions against bundled defaults before adapters apply them. A theme definition does not contain arbitrary CSS, application behavior, or alternate feature layouts.
- **Brain raw log**: the append-only record of every durable chat message (both directions), written synchronously at message-save time into the `BrainLog` Mongo collection by a fire-and-forget wrapper around `saveMessage`. It doubles as the distillation queue: entries carry a status machine (`pending → processing → skipped | awaiting_approval | applied | rejected | failed`) with atomic claims, a quiet-window debounce, and an attempts cap. The reply path never waits on it.
- **Ingestion gate**: the two-step LLM decision run by the brain distiller worker over claimed inbound raw-log entries — cheap triage (durable vs. ephemeral) then distill (known / merge / create against the vault's related notes). Both steps are tool-less and treat message content strictly as data. Merge/create outcomes write wikilinked vault notes, parked behind approval when `BRAIN_WRITE_APPROVAL` is on.
